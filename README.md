# ❄️ Sistema de Gestión de Mantenimiento - Refrigeración

Sistema web para gestionar el cronograma de mantenimiento del sistema de refrigeración industrial.

## 🚀 Ver la app

👉 **https://TU-USUARIO.github.io/refrigeracion**

## 📋 Funcionalidades

- 📊 Dashboard con KPIs en tiempo real
- 📅 Cronograma de mantenimiento con filtros
- 📆 Calendario mensual interactivo
- 🔧 Gestión de equipos
- 👷 Gestión de técnicos
- 📄 Reportes en PDF y Excel
- 🔔 Notificaciones de tareas vencidas
